## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| `lucide-react` brand-icon import | Lucide stripped `Github`, `Instagram`, `Youtube` etc. from the package in 2024 over trademark concerns. Imports look valid in TS but fail at runtime. Discovered Phase 2 Plan 02-03. | advisory | Always use inline `currentColor` SVG sub-components (pattern: `components/icons/InstagramIcon.tsx`, `components/icons/GithubIcon.tsx`). Memory entry `reference_lucide_brand_icons.md` documents the workaround. Plan 03 is unlikely to need brand icons (the bio is prose, not iconography), but if it does — DO NOT `import { X } from 'lucide-react'` for brand glyphs. |
| Tailwind v4 `transition-colors` interpolates `outline-color` | Phase 2 Plan 02-04 discovered the shorthand bleeds into `outline-color`, causing the focus ring to capture in-flight muted color on currentColor inheritors. Spec regressed in `tests/focus-ring.spec.ts`. | advisory | On any `<a>` that inherits `currentColor` (e.g., the CTAArrowLink reused in /about, Footer SocialIconLinks), use `transition-[color]` (arbitrary single-property) instead of `transition-colors`. Existing Phase 2 components already do this; reuse them as-is. |
| View-transition discipline: per-element only | D-22 from Phase 2 — NEVER add a project-wide `<ViewTransition>` wrapper at app/layout or app/page level. The seam is per-element via inline `style={{ viewTransitionName: '...' }}`. | advisory | /about must wire the matching `view-transition-name: hero-photo` ONLY on the photo wrapper, not on the page or layout. Encoded in CONTEXT.md D-17. |
| ABOUT-01 AI-template-phrase ban | REQUIREMENTS.md explicitly forbids "passionate developer," "I love to learn," "I am driven by," "innovative," "cutting-edge," "I am a [role] with experience in [list]" in /about copy. | advisory | First-pass bio draft passes a manual cliché-scrub before commit. CONTEXT.md D-05 captures the explicit list. Consider a Playwright spec that greps the deployed /about HTML for forbidden phrases (e.g. `/passionate\|cutting-edge\|driven by/i.test(text)` → fail). |
| YouTube scope amendment (Phase 2 → Phase 3 carryforward) | Phase 2 02-SCOPE-AMENDMENT.md drops YouTube from v1; Instagram + GitHub only. Component shape platform-keyed for forward-compat. | advisory | If /about bio prose mentions content channels, mention Instagram (`@braehods` / "DM me") only — never YouTube. Future channel addition is a one-line `data/channels.ts` edit + re-render. |

## Critical Anti-Patterns (do NOT repeat these)
- **DO NOT** import brand icons from `lucide-react` — always inline currentColor SVG per `components/icons/` pattern
- **DO NOT** use `transition-colors` on `<a>` elements that inherit currentColor — use `transition-[color]` (arbitrary single-property)
- **DO NOT** add a `<ViewTransition>` wrapper at `app/layout.tsx` or `app/page.tsx` level — per-element inline `style={{ viewTransitionName: '...' }}` only (D-22)
- **DO NOT** write "passionate developer," "cutting-edge," "I am driven by," "I love to learn," "innovative," or "I am a [role] with experience in [list]" in /about bio — ABOUT-01 ban (CONTEXT.md D-05)
- **DO NOT** mention YouTube anywhere in /about prose, social icons, or aria-labels — Phase 2 scope amendment carry-forward
- **DO NOT** add `'use client'` to any /about file — FOUND-07 / D-25 invariant; /about is Server Component
