## DEVIATIONS logged (for the eventual 06-02-SUMMARY.md)

(carried from the Task-3 marker; additions appended)

1. **[Rule 1 - Bug] canonical-urls spec accepted Next root-canonical normalization.**
   Next.js resolves the `/` canonical against `metadataBase` to the bare origin
   `https://braehods.com` (no trailing slash). The W0 spec expected
   `https://braehods.com/`. Fixed the spec (committed in `abd06e3`) to accept both
   bare-origin and trailing-slash forms for `/`; `/about` + `/work` stay exact.
   NOTE for verifier: the must_haves truth line says `https://braehods.com/`.

2. **proxy.ts dropped the unused `_request` param** (RESEARCH Pattern 5 included
   it but it triggered no-unused-vars). Signature is now `export function proxy()`.
   No behavior change.

3. **[Rule 3 - Blocking] satori `background-size` two-value requirement (T5 + T6).**
   `next/og` (satori) throws `(cssText || "").split is not a function` from
   `parseSimpleList` when `backgroundSize: '200px'` (single value) is paired with
   a data-URI `backgroundImage`. Fixed by using the equivalent two-value form
   `backgroundSize: '200px 200px'` in both the static-OG script and the two
   dynamic OG route segments. Documented inline in each file.

4. **[Rule 3 - Blocking] static-OG script uses React.createElement + runtime
   path-read (T5).** Bare `node` cannot parse JSX or import `.ts`, and `next/og`
   does not resolve under bare-node's `exports` map. Resolutions, all documented
   in `scripts/build-static-og.mjs`:
   - Build the element tree with `React.createElement` (no JSX transform needed).
   - Load `ImageResponse` via `createRequire(import.meta.url)('next/og.js')`
     (the concrete CJS entry).
   - Source `MONOGRAM_PATH` by reading `lib/og/monogram-path.ts` as text and
     extracting the literal at runtime — preserves the triple-source
     byte-identity guarantee (no hand-copied path that could drift).

5. **[Note, not a deviation] static OG PNG is RGBA, not RGB-no-alpha.** The plan
   frontmatter artifact line said "PNG binary, RGB no-alpha"; satori always emits
   8-bit RGBA. The charcoal gradient fully covers the canvas so alpha is opaque
   throughout — functionally equivalent; OG crawlers accept RGBA. Flag for
   verifier; no action needed.

6. **[Note] UI-SPEC Dimension 5 FLAG resolved to the multiples-of-4 attempt.**
   `scripts/build-static-og.mjs` uses `OG_NUDGE_PX = -39` (monogram center ~y=276,
   wordmark baseline ~y=444). To fall back to the spec y=275/445, set
   `OG_NUDGE_PX = -40`, re-run the script, re-commit the PNG. Final optical
   confirmation happens at Task 11.
