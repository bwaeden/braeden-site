## Spacing Scale

**Inherited from Phase 1 + Phase 2 + Phase 3 verbatim** (multiples of 4). Phase 4 introduces **zero** new spacing tokens. Card internals + grid gaps consume tokens from the existing scale.

| Token | Value | Tailwind class | Phase 4 usage |
|-------|-------|----------------|---------------|
| `xs` | 4px | `gap-1` / `mt-1` | Status-badge dot to label gap. |
| `sm` | 8px | `gap-2` / `mt-2` | Card title to description gap (within the card body); description to tags gap. |
| `md` | 16px | `gap-4` / `mt-4` | Status badge to title gap (within the card body); **mobile grid gap** between stacked cards. |
| `lg` | 24px | `gap-6` / `mt-6` | **Desktop grid gap** between cards (column-gap and row-gap both `md:gap-6`). |
| `xl` | 32px | `gap-8` / `p-8` | Not used in /work composition — reserved. |
| `2xl` | 48px | `py-8 md:py-12` | Section vertical padding on the page-level `<section>`. Same as Phase 2 home hero + Phase 3 about per CD-05 inheritance. |
| `3xl` | 64px | `gap-16` | Not used in /work composition — reserved. |

**Card internal padding (D-01 — refined):** **`p-5`** (20px) on the card root. On-grid (multiple of 4 — 5 × 4 = 20). Slightly tighter than the photo-tile's 8px outer ring + body to keep the 7-card grid feeling browse-able rather than browse-heavy. Planner may bump to `p-6` (24px) at execute time if the visual-rhythm sweep flags 20px as cramped against the description's 140-char ceiling — document the swap as a one-line note in the plan summary if used.

**Card corner radius (D-01):** `rounded` (4px). Matches the photo-tile radius from Phase 2 D-02. Same editorial restraint — not pill, not square.

**Card border (D-01):** `1px solid var(--color-border)` (#2a2a2f) on rest. Matches photo-tile hairline. Transitions to `1px solid var(--color-accent)` (#7c87ff) on `:hover` per D-02 (transition-property discipline below).

**Grid gap (D-05 — refined):**
- Mobile: `gap-4` (16px) — single column, vertical gap between stacked cards.
- Desktop (`md:` and `lg:`): `gap-6` (24px) — both column-gap and row-gap.

**Within-card vertical rhythm** (top-to-bottom inside the card body — D-10 read order: status → title → description → tags):

| From → To | Gap (px) | Tailwind class | Rationale |
|-----------|----------|----------------|-----------|
| Status badge → Title | 16px | `mt-4` | Status is metadata; title is the name. Comfortable separation. |
| Title → Description | 8px | `mt-2` | Tight pair — description is the title's elaboration. |
| Description → Tags | 8px | `mt-2` | Tight pair — tags are description-adjacent metadata. |

**Status-badge dot diameter:** **6px** (`w-1.5 h-1.5` via Tailwind v4 `0.375rem`). Matches Phase 2 CurrentlyLine accent dot (CD-02 inheritance). Sub-grid by design — visual signal, not a layout spacer.

**Exceptions** (Phase-4-specific): **None.** All spacers are multiples of 4. No `0.5` / `2.5` / `3.5` fractional Tailwind utilities used in any component contract.

**Hard rules** (inherited from Phase 1 / Pitfall 3 — restated for executor):

Phase 6 Lighthouse audit confirms.

NOT centered (draws attention to the asymmetry). NOT spans-2 (would visually weight the orphan, conflicting with WORK-01 "equal-weight, no flagship hierarchy"). NOT lower opacity on the orphan or any card (fights equal-weight per D-08).

**Transition contract (D-02 — non-negotiable):**
- `transition: border-color 200ms cubic-bezier(0.2, 0, 0, 1), color 200ms cubic-bezier(0.2, 0, 0, 1), transform 200ms cubic-bezier(0.2, 0, 0, 1)`
- Tailwind shorthand: `transition-[border-color,color,transform] duration-200 ease-[cubic-bezier(0.2,0,0,1)]`
- **Explicitly NOT `transition-colors`** — Phase 2 Plan 02-04 lesson: Tailwind v4's `transition-colors` shorthand transitions `outline-color` in addition to `color`/`border-color`/etc., which combined with the `:focus-visible` accent ring causes the 2px ring to interpolate from inherited muted to accent on Tab focus. The narrow `transition-[border-color,color,transform]` arbitrary list keeps `outline-color` un-animated. This is the SAME bug class fixed in Footer.tsx + SocialIconLink.tsx during Phase 2.

**`will-change`:** `will-change: auto` (do NOT promote to a layer — same lesson as Phase 1 grain rule + Phase 2 ChannelButton).

**Why the entire card is the link (D-03 vs alternatives):**
- Single `<a>` wrap = 1 keyboard tab stop per card (7 total on /work). With 4 Nav stops + 7 cards + 2 footer socials = ~13 tab stops total — clean keyboard journey.
- Mobile touch target trivially exceeds 44×44 floor (the entire card is ~372px wide × ~140px tall).
- Hover state applies uniformly to the entire card — border accent + arrow translate fire together; no nested-link complications.
- Alternative considered + rejected: title-only `<a>` with the rest of the card content non-interactive — would create 2 click affordances (the card surface looks clickable but isn't, plus the title is a separate click target). Confusing.

import { projects } from '@/data/projects';

- Stagger total completes ~960ms after page interactive — comfortable for 7 elements, not slow. (Compare: Phase 2 home hero finishes at ~880ms with 6 elements.)
