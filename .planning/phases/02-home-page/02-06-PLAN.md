## Hero composition pattern (from 02-PATTERNS.md lines 68-91)
```tsx
<section data-test="hero-section" className="py-8 md:py-12">
  <div className="mx-auto flex max-w-5xl flex-col-reverse gap-8 md:flex-row md:items-center md:gap-16">
    <div className="flex flex-col items-start">
      <h1 data-test="hero-display" className="font-serif text-[clamp(4rem,12vw,6rem)] leading-[1.05] font-bold">
        Braeden
      </h1>
      <p
        data-test="hero-positioning"
        className={`mt-4 font-sans text-lg leading-relaxed max-w-[44ch] ${fadeInUp}`}
        style={{ color: 'var(--color-text)', ...stagger(1) }}
      >
        {site.tagline}
      </p>
      <CurrentlyLine data={currently} />
      <ChannelButtonRow channels={channels} />
      <div className="mt-6 flex flex-col gap-2">
        <CTAArrowLink href="/about" staggerIndex={5}>More about me</CTAArrowLink>
        <CTAArrowLink href="/work" staggerIndex={6}>See the work</CTAArrowLink>
      </div>
    </div>
    <HeroPhoto />
  </div>
</section>
```

Key annotations:
- `flex-col-reverse` on mobile + `md:flex-row` on desktop — markup order is text-then-photo so screen readers read text first; visual order on mobile is photo-then-text via `flex-col-reverse` (UI-SPEC line 185-186).
- `gap-8` mobile = 32px vertical between photo and text on mobile.
- `md:gap-16` desktop = 64px horizontal between text column and photo column.
- The hero `<section>` does NOT have horizontal padding — `<main>` already supplies `px-6 lg:px-12`. The hero just needs vertical padding `py-8 md:py-12` (UI-SPEC line 196 — py-8 mobile, py-12 desktop).
- The text-column `<h1>` has NO `mt-*` — it's the first element in the column.

## What goes on the OUTER vs INNER element
- Outer `<section>`: `data-test="hero-section"` + `py-8 md:py-12` only. No max-width here (the inner `<div>` owns it).
- Inner `<div>`: `mx-auto flex max-w-5xl ...` — applies the 1024px max-width and the flex layout. `max-w-5xl` widens beyond `max-w-3xl` from `<main>` only for the hero block; root layout's prose-width is preserved for `/about` and `/work` stubs.

## Required Tailwind invariants (UI-SPEC line 73)
- All padding/gap/margin utilities are integer multiples of 4: `py-8`, `py-12`, `gap-8`, `gap-16`, `mt-4`, `mt-6`, `gap-2`.
- Documented exceptions in Hero scope: `max-w-[44ch]` is content-width (not a spacer); `max-w-5xl` is a Tailwind named token; `text-[clamp(4rem,12vw,6rem)]` is a typography clamp (Phase 1 ships this).
