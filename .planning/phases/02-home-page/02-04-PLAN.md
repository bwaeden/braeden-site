SocialIconLink wraps each icon in `inline-flex items-center justify-center p-2` → ~34×34 tactile target. Falls short of WCAG 44×44 ideal. This is the editorial-restraint trade-off documented in UI-SPEC; Phase 6 a11y audit can revisit if real-device testing flags it.

## Required Tailwind class invariants (UI-SPEC line 73)
- Allowed: `gap-4` (16px), `p-2` (8px). Both integer multiples of 4.
- Forbidden: `gap-1.5`, `p-1.5`, etc.

```tsx
export function SocialIconLink({ href, label, Icon }: SocialIconLinkProps) {
  return (
    <a
      href={href}
      target="_blank"
      rel="noopener noreferrer"
      aria-label={label}
      className="inline-flex items-center justify-center p-2 transition-colors duration-200 hover:text-[var(--color-text)]"
    >
      <Icon size={18} strokeWidth={1.75} aria-hidden />
    </a>
  );
}
```

Details:
- `target="_blank" rel="noopener noreferrer"` — required on every external link (HOME-06 + tabnabbing prevention).
- `aria-label={label}` — required because the icon has no visible text label (UI-SPEC line 472-475).
- `<Icon aria-hidden />` — the icon is decorative; the `<a>`'s aria-label carries the semantic.
- NO explicit color on the `<a>` — the parent `<footer>` sets `color: var(--color-muted)` (Task 2 ensures this is on the container) and `currentColor` cascades into the lucide SVG's stroke (lucide icons use `currentColor` for stroke by default per D-16).
- `hover:text-[var(--color-text)]` — Tailwind arbitrary, on the `<a>` element, so the cascade-controlled icon stroke transitions to the brighter text token on hover.
- `transition-colors duration-200` — 200ms easing matches the channel-button hover transition timing (consistent feel across the page).
- `p-2` (8px) gives the click target a buffer beyond the 18px icon → ~34×34 tactile area. Accepted trade-off per UI-SPEC line 469.
