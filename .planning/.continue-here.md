## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Splitting an atomic-binding refactor across waves | Phase 5 D-05 binding required 4 files in ONE commit (`app/layout.tsx` mount + `Nav.tsx` href + `about/page.tsx` href + `about-renders.spec.ts` assertion). Plan-checker rejects split-Wave variants; executor enforces by `git log -n 1 --name-only` post-commit verify. | advisory | Phase 6 should declare any cross-file rename/refactor as a single-commit binding in its plans. The pattern is reusable: stage all paths together, `git commit` once, verify name-list immediately. |
| Adding a 2nd `'use client'` directive without dual-gate update | FOUND-07 carve-out activated in Phase 5 (ContactModal.tsx is the SOLE `'use client'`). `tests/single-client-island.spec.ts` (filesystem count) + `tests/no-client-components.spec.ts` (allow-list) both guard the invariant. | blocking | If Phase 6 needs a 2nd client island, update BOTH specs atomically in the SAME commit as the new directive. The count spec must flip to `expect(N)`; the allow-list spec must add the new path to `ALLOWED_CLIENT_ISLANDS`. Both gates will RED on any unsanctioned addition. |
| Hash-driven UI listening ONLY to `hashchange` | Next.js `<Link href="#...">` calls `history.pushState` and does NOT fire `hashchange`. ContactModal originally listened only to hashchange; the modal stayed closed after the D-05 swap until commit `e9206a5` added a bubble-phase document click listener. | advisory | Any new hash-anchored UI (search modal, command palette, etc.) needs the dual-listener pattern: `hashchange` for back/forward + deep-link + `location.hash` assignment, PLUS a bubble-phase document click listener detecting `anchor.hash === target` and acting directly. Modifier-key + non-primary clicks bail; do NOT bail on `event.defaultPrevented` (Next.js sets it because it's handling the hash). |
| `location.hash = ''` to clear hash on close | Leaves the same `#contact` cached; subsequent same-hash click does NOT fire `hashchange`. | advisory | Use `history.replaceState(null, '', window.location.pathname + window.location.search)` instead. Already enforced in ContactModal.tsx; reuse the pattern in any future hash-clearing close handler. |
| Tailwind v4 `transition-colors` shorthand on interactive elements with focus rings | Includes `outline-color`; combined with a parent muted-color cascade and the `:focus-visible` 2px accent ring, the ring 200ms-interpolates from muted to accent and tests flake. Hit in Phases 2, 4, and 5. | advisory | Use `transition-[border-color,color,opacity]` arbitrary-list. Already encoded in ContactModal.tsx + Footer SocialIconLink + ProjectCard; carry the discipline into any Phase 6 interactive element. |
| Honeypot field named `_gotcha` | Formspree's documented default — spam scrapers fingerprint it and skip it. Phase 5 used `name="company"` per D-13. | advisory | Phase 6 should not regress this — and any future form should also avoid `_gotcha` as a documented default. |
